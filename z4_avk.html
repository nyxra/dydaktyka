Zadanie 4 - teoria JavaScript (Veronika Avksentieva, klasa 3F)

1) Kiedy powstał JavaScript (podaj datę).
JavaScript powstał w 1995 roku. W grudniu 1995 roku został zaimplementowany w przeglądarce Netscape Navigator.

2) Dlaczego jest to język skryptowy?
Ponieważ jest językiem interpretowanym - nie trzeba go kompilować do kodu maszynowego, aby zobaczyć efekty działania. Wystarczy przeglądarka internetowa, która obsługuje ten język.

3) Gdzie jest wykonywany JS (klient lub serwer)?
Po stronie klienta - w przeglądarce internetowej użytkownika. (Dzięki Node.js można go też uruchamiać na serwerze.)

4) Dlaczego JS jest bezpiecznym narzędziem?
Ze względów bezpieczeństwa JavaScript ma znacznie ograniczone uprawnienia dostępu do zasobów komputera, na którym przeglądana jest strona.

5) Czy jest to język obiektowy, jeśli tak to dlaczego?
Tak. JavaScript wykorzystuje definicje obiektów, metod i zdarzeń, które opisują właściwości obiektów. Struktura obiektów jest określona przez DOM (Document Object Model). Można korzystać z gotowych obiektów i metod, tworzyć własne oraz modyfikować istniejące.

6) Wymień zalety JS:
Zaleta1: prostota - język jest relatywnie łatwy do opanowania, można zacząć go używać po kilku minutach nauki.
Zaleta2: jest najbardziej rozpowszechnionym językiem skryptowym, w Internecie są miliony praktycznych przykładów.
Zaleta3: uniwersalność oraz odciążenie serwerów i ograniczenie ilości zbędnych danych przesyłanych między serwerem a przeglądarką.

7) Framework to:
Rodzaj programu do tworzenia innych programów w JS, np. Angular (Google) lub React (Facebook).

8) Do aplikacji mobilnych można użyć Framework:
React Native - pozwala budować aplikacje mobilne na różne systemy operacyjne (cross-platform apps).

9) Aplikacje responsywne to:
Aplikacje, które dopasowują wygląd do rozmiaru ekranu. JavaScript pobiera bieżący rozmiar ekranu, a na tej podstawie (razem z CSS i HTML) treści są zmniejszane, powiększane, ukrywane lub przenoszone, aby dobrze wyglądały na dowolnym ekranie.

10) Linia kodu i wytłumaczenie:
‹input type="button" name="przycisk" value="Nowa Strona" onclick="WinOpen(' ')"›
Tworzy przycisk (type="button") o nazwie "przycisk" z napisem "Nowa Strona" (value). Kliknięcie przycisku myszką (zdarzenie onclick) uruchamia funkcję WinOpen(), która otwiera nowe okno.

11) Linia kodu i wytłumaczenie:
window.open("obraz.html","okienko","toolbar=no,directories=no,menubar=no,height=280,width=160,top=200,left=200");
Metoda window.open otwiera nowe okno przeglądarki i wczytuje do niego plik obraz.html. "okienko" to nazwa nowego okna, a trzeci parametr to lista ustawień okna:
toolbar=no - ukrywa pasek narzędzi (przyciski nawigacji)
directories=no - ukrywa pasek katalogów (zakładek/linków)
menubar=no - ukrywa pasek menu
height=280 - wysokość okna 280 pikseli
width=160 - szerokość okna 160 pikseli
top=200 - okno jest 200 pikseli od górnej krawędzi ekranu
left=200 - okno jest 200 pikseli od lewej krawędzi ekranu

12) Opisz instrukcję window.close()
Metoda window.close() zamyka bieżące okno przeglądarki (działa dla okien otwartych przez skrypt metodą window.open).
