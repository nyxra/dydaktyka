1) Rodzaje okienek
Okienko alert – wyświetla okienko dialogowe z informacją i przyciskiem OK.
Okienko prompt – generuje okno, w którym użytkownik może wpisać wartość, zwracaną następnie do programu.
Okienko confirm – służy do tego, aby użytkownik coś potwierdził (OK lub Anuluj).

2) Konwersja liczb
Wczytanie zmiennej przy użyciu prompt daje ciąg znaków, dlatego aby wykonywać obliczenia, trzeba zamienić tekst na liczbę:
parseFloat(zmienna) – konwersja zmiennej do typu float (liczba zmiennoprzecinkowa),
parseInt(zmienna) – konwersja zmiennej do typu int (liczba całkowita),
toString(zmienna) – konwersja zmiennej do typu łańcuchowego (tekst).

3) Przy nadawaniu nazw zmiennym należy przestrzegać pewnych zasad (trzy zasady)
1. Nazwa zmiennej musi się zaczynać od litery, znaku "$" lub "_", może zawierać tylko litery (bez polskich znaków), cyfry oraz "$" i "_".
   Poprawne: zmienna1, $wynik, _rozmiar   Błędne: 1zmienna, wynik gry, wysokość
2. Wielkość liter ma znaczenie – Rekord i rekord to dwie różne zmienne.
3. Nie należy używać słów kluczowych JavaScript jako nazw zmiennych.

4) Omów typy zmiennych w Javascript
W JavaScript typy zmiennych nie są deklarowane jak w C++ – typ jest określany w chwili przypisania wartości.
Number – typ liczbowy (liczby całkowite i zmiennoprzecinkowe),
String – typ tekstowy,
Boolean – typ logiczny (true / false),
Null – pusta zawartość,
Undefined – typ niezdefiniowany (zmienna bez wartości),
Object – obiekt.
