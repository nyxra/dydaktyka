Avksentieva Veronika &bdash; Rodzaje stylów CSS

CSS mozna podzielic na tzy typy ze wzgledu na miejsce definicji:

  1. Styl liniowy(inline)
    1. Definiowany w atrybucje style="" znacznika HTML
      1. Najwyzszy priorytet, trudny w utrzymaniu
      2. Przyklad: < p style="color: red;" >
  2. Styl wewnetrzny(internal)
    1. Definiowany w sekcji %i=lt; head> w znaczniku < style>
      1. Dziala tylko dla jednej strony HTML
      2. Przyklad: <:style> p { color: red; } </style>
  3. Styl zewnetrzny(external)
    1. Definiowany w osobnym pliku .css, dolaczenym przez <link&ht;
      1. Najlepsza praktyka - jeden plik CSS dla wielu stron
      2. Przyklad: <link rel="stylesheet" href="styl.css"&ht;
